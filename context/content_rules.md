# AHW Architects — Content Rules

Status: **Approved working context**
Scope: **Global master brand**

## 1. Source-of-Truth Rule

AI-generated content must use approved repository, website, project, and campaign information.

If a fact is missing, ambiguous, outdated, or conflicting:

**STOP — do not invent it.**

Ask for confirmation or omit the claim.

## 2. Fact vs. Interpretation

Clearly distinguish:

- Verified project facts.
- Approved brand positioning.
- Professional interpretation.
- Editorial opinion.

Do not present interpretation as a measured project result.

## 3. Claims

Never invent or imply:

- Client identities.
- Project budgets.
- Completion dates.
- Project areas.
- Savings percentages.
- ROI.
- Performance improvements.
- Sustainability credentials.
- Awards.
- Certifications.
- Number of offices.
- Number of employees.
- Geographic coverage.
- Construction methods.
- Material certifications.

unless the claim is supported by an approved source.

## 4. Project Content

For project posts, use only information confirmed for that project.

Preferred structure:

1. Brief.
2. Challenge.
3. Design decision.
4. Technical / delivery decision.
5. Outcome.
6. Relevant insight.

Never fabricate a challenge merely to make a case study more dramatic.

## 5. Images and Renders

Do not describe a render as a completed built project unless the source confirms completion.

Do not claim construction quality from an image alone.

For before/after content, identify clearly whether imagery represents:

- Existing condition.
- Design proposal.
- Construction progress.
- Completed work.

## 6. Before / After Transformations

The transformation should explain the underlying decisions, not merely celebrate the visual difference.

Where available, discuss:

- Planning.
- Circulation.
- Light.
- Materiality.
- Detailing.
- Engineering.
- Procurement.
- Execution.

## 7. Technical Accuracy

Use technical terminology when it is correct and useful.

Never use technical terms as decorative language.

When discussing materials or systems, define the performance criterion:

- Durability.
- Slip resistance.
- Acoustic performance.
- Fire performance.
- Moisture resistance.
- Maintenance.
- Thermal performance.
- Wear resistance.
- Installation tolerance.

Only state a performance value when verified.

## 8. Commercial Content

Connect design to business consequences where supportable:

- Programme.
- Cost.
- Risk.
- Maintenance.
- Operational efficiency.
- Asset value.
- Brand experience.

Never guarantee financial outcomes.

## 9. Competitors

Do not attack, name, mock, or make unsupported claims about competitors.

Position AHW through its own capability and evidence.

## 10. Tone Controls

Do:

- Be confident.
- Be specific.
- Be concise.
- Explain why.
- Show evidence.
- Respect the audience's intelligence.

Do not:

- Shout.
- Overuse exclamation marks.
- Use fake urgency.
- Use empty luxury clichés.
- Overuse emojis.
- Sound like a discount contractor.
- Sound like an academic paper.
- Overuse buzzwords.

## 11. SEO

SEO must never make the brand sound unnatural.

Use relevant service, sector, and location terminology where it genuinely describes the page.

Do not keyword-stuff.

Do not create thin location pages with interchangeable text.

## 12. Social Content

Every post should have one primary idea.

The opening should create a reason to continue reading.

The body should provide substance.

The CTA should be appropriate to the audience and buying stage.

Avoid generic CTAs such as "DM us now" unless the campaign specifically requires that behavior.

## 13. Hashtags

Use relevant, defensible hashtags.

Do not generate large blocks of generic hashtags solely to increase apparent reach.

Hashtags must not replace meaningful copy.

## 14. Localisation

Maintain the global brand voice while adapting:

- spelling conventions.
- terminology.
- currency.
- units.
- local market references.
- contact route.
- local project proof.

Never localize by inventing local claims.

## 15. Arabic

Arabic content should read as natural professional Arabic for the target market.

Do not produce literal word-for-word translations when they weaken meaning or tone.

Preserve the same level of technical precision and brand restraint as English.

## 16. CTA Hierarchy

Match the CTA to intent:

Awareness → Explore the work / Read the insight.

Consideration → Explore the service / Discuss your project.

High intent → Start a project conversation / Request a consultation.

Do not use high-pressure CTAs on every post.

## 17. Approval Gate

Before publication confirm:

- Source verified.
- Project status verified.
- Claims verified.
- Brand voice aligned.
- Audience identified.
- Content pillar identified.
- CTA appropriate.
- Market/localization correct.
- Image status clear.
- No confidential or private information exposed.

## 18. Quality Test

A strong AHW content item should pass this question:

> Could a technically experienced client learn something useful about design, construction, delivery, or value from this content?

If not, improve the substance before polishing the wording.
